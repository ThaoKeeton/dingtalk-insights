# 常规整理模型判断实施计划

自主实施，不暂停等待常规设计确认。基线及兼容性设计见同日期 `routine-model-assessments-design.md`。

1. 用真实生产报告路径的合成 `resolved` 复现模型判断丢失，覆盖重开、可选人工确认/撤销及旧历史。
2. 保留原规范 Markdown 与人工状态，持久化原始模型状态并单独渲染可直接使用的报告；损坏/保存失败不虚报成功。
3. 更新两个原生界面和模拟数据，用真实按钮验证无需人工复核即可查看模型判断；保留人工确认、费用、未知结果及发送边界。
4. 使用精确旧版源码以独立进程验证新→旧读写→新、保留报告/人工决定与预算；运行核心、插件桥接、包维护和 SDK 字节检查。
5. 独立审查后提交独立分支，运行两条公开 Windows Actions，检查精确提交和产物；报告真实接口及最终平台集成未验证范围。
