# 长期监控与按需整理 MVP

用户目标：独立 Windows 图形应用，长期检查选定钉钉会话，用可配置低价模型发现可能的沟通难点；用户提出整理事项后，软件搜集相关消息并整理。结果在界面查看，也可手动发送 Webhook。用户已在自己的本机验证 DWS 权限可行；开发环境不复用或导入其登录。

## 实现选择

采用 WinUI 3 / .NET 8 Windows 原生界面（与 UPCAM 的 NavigationView、Mica、设置卡片体验一致），加不依赖 Windows 的 .NET 核心。直接调用已安装的官方 DWS 可执行文件，不搬运 DWS 凭据，不访问钉钉客户端数据库。与 Python worker 相比，单一 .NET 运行时减少进程协议与双运行时打包；Web/Electron 会偏离用户要求的原生体验。

## 两条主要流程

1. 持续检查：明确身份、单一会话、开始时间、间隔、保留期及是否允许模型上传 → 预览并授权本次运行 → 每次读取最多一小时的增量窗口 → 加密保存消息与覆盖区间 → 完整批次推进断点，重叠两分钟去重 → 尚未尝试的消息最多 40 条一批 → 请求前持久保存费用预留与尝试记录 → 模型给出带证据的待核实候选 → 界面查看。缺页、授权失败、保存失败或预算耗尽时暂停；用户恢复后从断点追赶。不会自行发送消息。
2. 按需整理：用户输入事项 → 核对可编辑关键词、身份、会话和时间 → 搜索本机已采集索引，或经确认通过 DWS 检索 → 查看最多 40 条实际候选原文 → 确认向 OpenAI 上传这一批正文与整理事项 → 验证结果结构和原文引用 → 查看、导出，或预览完整正文和目标群后确认发送一次。关键词检索不代表穷尽所有同义表达；范围外历史和未读附件始终提示限制。

每次启动均为模拟模式，监控需要显式开始。首版持续检查在窗口运行期间执行；关闭、休眠和断网期间不提供实时保证，再次开始使用断点补查，不宣称是 Windows 后台服务。

## 断点、成本与持久数据

本机消息索引按身份、会话和消息 ID 去重，修订内容更新记录；完整覆盖区间合并时不跨越缺口。断点、消息修订、模型尝试记录、费用预留和最近结果使用一个原子替换的 DPAPI 加密状态文件，单实例文件锁防止并发覆盖。默认保留 30 天，最多 50000 条消息、32 MiB 加密状态和 100 份结果，超限暂停。

默认模型 `gpt-6-luna`，输入/输出参考单价为 USD 0.10/0.50 每百万 tokens，来源核对日期 2026-11-06；模型和单价均可配置。请求使用文本与严格 schema，最多 48 KiB 请求、2000 输出 tokens；按 UTF-8 字节数加 framing 余量保守预留费用。每日默认预留上限 USD 0.50、最多 200 次请求，按 UTC 日计。失败、超时和进程崩溃不返还预留；监控不会自动重试同一修订的未知模型结果。该限制仅覆盖本应用依据配置单价估算的用量，不是平台账单或账户全局消费保证。

## 安全和可信边界

- 聊天正文与模型输出都不是操作指令。模型没有工具；消息文本仅进入 user 数据载荷，固定开发者指令优先。界面只用纯文本控件，不执行 HTML、命令、链接或远程图片。
- 每个问题必须有至少一条可核验的消息 ID 和逐字原文片段；不存在的 ID、非原文引用、无证据的状态、结构错误和不完整的模型响应均拒绝。
- 模型的 resolved 一律变为 pending_verification；只有用户针对当前问题与证据明确确认，才会显示已解决。重做整理即丢弃旧的人工确认。
- DWS 的完整性 ledger、分页失败和截断保留。未知或矛盾字段按不完整处理；即使分页结束，也不承诺附件、撤回、服务端索引和历史范围全部可见。
- 只读取当前用户明确选择的会话，不自动扩大到所有会话。固定命令列表、ArgumentList、无 shell；DWS 非零状态不能被当作完整成功。
- OpenAI 端点固定为官方 HTTPS，Responses API、store=false、无工具、严格 JSON schema；客户端关闭重定向，限制请求/响应大小和超时，无自动重试。
- Webhook 仅允许 https://oapi.dingtalk.com/robot/send，禁止重定向和 @所有人；支持 HMAC 加签。超时视为结果不确定，不能自动重发。
- 本机凭据由 Windows DPAPI CurrentUser 加密保存到 LocalAppData，窗口不回显已保存密钥；配置不含密钥。开发环境密钥的创建和仓库外保存另行确认，不依赖该步骤执行模拟测试。
- 一次性读取、按需 OpenAI 上传与 Webhook 发送需要对应确认。持续检查的授权绑定明确身份、单一会话、起始时间、模型、预算和当前运行期；修改配置需先停止并重新授权。Webhook 始终手动确认，不随监控授权自动发送。
- 不把原文、密钥、服务响应体或带查询参数的 Webhook 写入日志。原文只在内存与本机 DPAPI 加密索引中保存，导出需用户显式选择。
- 模型结论只作为待核实候选，不用于人员能力、人格、动机或绩效评价。逐字引用校验只能验证引用来自输入，不能证明模型理解正确，仍需要人工核实。

## 首版范围

范围：模拟完整链路、DWS 会话发现与单会话按时间增量读取、断点恢复和去重、本机加密索引及关键词搜索、按需 DWS 搜索、可配置低价模型和费用上限、原文预览、证据校验、人工确认、Markdown 导出与手动 Webhook、主题选择、Windows 自包含 ZIP 与原生启动测试。

后续：实时事件订阅、长期问题合并与跨批次语义关联、自动更新、托盘和自启动、Windows 服务、多账户管理、附件内容提取。两分钟重叠不能保证捕获更早消息的编辑和撤回；首版不冒充完整实时审计工具。

首版为 Windows x64、Windows 10 19041+；界面为中文。DWS 由用户独立安装和授权，不捆绑静默安装。
